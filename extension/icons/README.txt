Drop three PNG mic icon files here before loading the extension:

  16.png   –  16×16 px
  48.png   –  48×48 px
  128.png  – 128×128 px

Suggested source: reuse the mic artwork from the Android app's
  app/src/main/res/drawable/ic_launcher_foreground.png

Export/resize it to the three sizes above using any image editor
(Android Studio's Image Asset Studio, Inkscape, GIMP, etc.).

Chrome will refuse to load the extension if any of these files are missing.
